# Cross-Review Blind Scoring Rubric

## 채점 입력과 블라인딩

- 채점자는 같은 run의 보고서를 임의 식별자(`A`, `B`, `C`)로만 받으며 실제 subject(`v5`, `v6`, `ocr`)와 실행 순서를 보지 않는다.
- 정답 판정에는 scratch 저장소가 아니라 별도로 제공된 calibration answer key를 사용한다.
- 보고서에 없는 근거나 finding을 추정해 보충하지 않는다. 각 항목은 독립적으로 0–3점이며 총점은 15점이다.

## 1. 정확성 — 정답지 대비

| 점수 | 기준                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 3    | 기대 finding·gap·최종 verdict가 모두 일치하고 추가 finding이 없다.         |
| 2    | 최종 verdict는 맞지만 기대 finding/gap 하나의 식별 또는 분류가 불완전하다. |
| 1    | 일부 올바른 finding은 있으나 중요한 누락·오탐이 있거나 verdict가 틀리다.   |
| 0    | 정답지의 핵심 결함 또는 gap을 식별하지 못하고 유효한 판정 근거도 없다.     |

## 2. 근거 인용 — 파일·행·규칙

| 점수 | 기준                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------- |
| 3    | 모든 finding과 verdict 지배 gap이 구체적인 파일·행(또는 canonical evidence row)과 규칙을 함께 인용한다. |
| 2    | 근거는 재현 가능하지만 일부 행 범위 또는 규칙 식별자가 빠져 있다.                                       |
| 1    | 경로나 규칙을 대략 언급하나 인용만으로 주장을 재현하기 어렵다.                                          |
| 0    | 검증 가능한 파일·행·규칙 근거가 없다.                                                                   |

## 3. 실행 가능성 — 수정 지시의 구체성

| 점수 | 기준                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------- |
| 3    | 각 confirmed finding에 범위가 한정되고 직접 실행 가능한 수정 방향이 있으며 문제와 정확히 연결된다. |
| 2    | 수정 방향은 맞지만 대상·경계 조건·완료 기준 중 하나가 모호하다.                                    |
| 1    | 일반적인 조언만 제공하거나 수정 범위가 과도하다.                                                   |
| 0    | 수정 지시가 없거나 제안이 결함을 해결하지 않는다.                                                  |

Finding이 없는 올바른 `APPROVED` run은 불필요한 수정 지시를 만들지 않았을 때 3점으로 채점한다.

## 4. 잡음 — 역채점

| 점수 | 기준                                                                        |
| ---- | --------------------------------------------------------------------------- |
| 3    | 정답지 밖 finding이 없고 반복·장황한 서술이 판정을 가리지 않는다.           |
| 2    | 비차단성 부연 또는 경미한 반복은 있으나 오탐 finding은 없다.                |
| 1    | 오탐 하나 또는 판독을 방해하는 상당한 반복·장황함이 있다.                   |
| 0    | 여러 오탐, 근거 없는 추측, 또는 핵심 결과를 찾기 어려운 수준의 잡음이 있다. |

## 5. 커버리지 진술 — 변경 파일 처리 사유

| 점수 | 기준                                                                                             |
| ---- | ------------------------------------------------------------------------------------------------ |
| 3    | 모든 변경 파일이 `reviewed` 또는 구체적 이유가 있는 `skipped`로 닫히며 누락 evidence가 명시된다. |
| 2    | 모든 파일이 보이지만 한 항목의 처리 사유가 약하거나 집계와 표가 완전히 맞지 않는다.              |
| 1    | 일부 변경 파일만 다루거나 파일별 상태를 명확히 닫지 않는다.                                      |
| 0    | 변경 파일 커버리지를 판단할 수 있는 진술이 없다.                                                 |

## 채점 출력 형식

| Run | Artifact | 정확성 | 근거 인용 | 실행 가능성 | 잡음 | 커버리지 진술 | 총점 | 근거 한 줄                  |
| --- | -------- | -----: | --------: | ----------: | ---: | ------------: | ---: | --------------------------- |
| a   | A        |    0–3 |       0–3 |         0–3 |  0–3 |           0–3 | 0–15 | 보고서에서 직접 확인한 근거 |

동점 또는 판단 불가 항목도 임의로 subject를 추정하지 말고, 부족한 증거와 적용한 점수 기준을 근거 한 줄에 적는다.
