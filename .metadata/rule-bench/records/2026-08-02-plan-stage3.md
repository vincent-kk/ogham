**공통 런 레시피** (T1~T3의 모든 런이 이 형태):

```bash
node .metadata/rule-bench/prepare.mjs --issue <id> --arm <R0|R1|R2|R3> --rep <n> --out <SCRATCH>/<runsDir>
# stdout: {"runDir":"<...>/<id>-<arm>-t<n>","prompt":"..."}
```

→ Agent(model: 태스크 지정, prompt 그대로) → 응답 전문을 `<runDir>/FINAL.md`로 Write →

**집계 스크립트** — `<SCRATCH>/aggregate.mjs`로 저장 후 재사용:

```js
#!/usr/bin/env node
// loaded by: manual invocation — node aggregate.mjs <file.jsonl> [...]
import { readFileSync } from 'node:fs';
const rows = process.argv.slice(2).flatMap((f) =>
  readFileSync(f, 'utf8').trim().split('\n').map((l) => JSON.parse(l)));
const groups = new Map();
for (const r of rows) {
  const k = `${r.issue}-${r.arm}`;
  const g = groups.get(k) ?? { n: 0, hidden: 0, total: 0, shownOk: 0, fullPass: 0 };
  g.n += 1; g.hidden += r.hiddenPassed; g.total += r.hiddenTotal;
  if (r.shownPassed === r.shownTotal) g.shownOk += 1;
  if (r.hiddenPassed === r.hiddenTotal) g.fullPass += 1;
  groups.set(k, g);
}
for (const [k, g] of [...groups].sort()) console.log(k, JSON.stringify(g));
```
