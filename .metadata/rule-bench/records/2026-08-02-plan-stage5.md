# rule-slim-r2 — 5단계: 볼드 테제 전면 복원판(R2b) 게이트 검증

> 2026-08-02. 4단계 검토에서 사용자 결정: "볼드 테제의 모든 규칙 적용 가능성을 검증해보자. 준수율이 올라간다면 채택할 수 있다." R2r(단일 복원) 재검증을 겸한다. 커밋은 사용자 결정.

## 0. 전역 제약 (모든 태스크가 상속)

**R2b 정의 — 마크업만, 문장 추가 없음**: 현행 배포본 14종 사본에서 각 번호 절(`## N.`) 헤딩 직하 **첫 산문 문단의 첫 문장**을 볼드 처리한다. 결정 규칙:

- 첫 문장 경계 = 첫 마침표(`.`) 또는 도입 콜론(`:`)까지, 뒤따르는 공백 전. 콜론으로 끝나는 리스트 도입문(reuse-first §1 형)은 콜론 포함.
- 절이 표·리스트·인용으로 시작해 산문 첫 문장이 없으면 건너뛴다(무리한 발명 금지).
- 문장 안에 이미 인라인 볼드/코드 스팬이 있으면 바깥에 `**...**`를 씌우되 중첩 볼드가 생기는 경우 그 절은 건너뛰고 기록한다.
- 문장 자체가 없어 v1에서 가져와야 하는 경우(R2p형 복원)는 하지 않는다 — 4단계에서 기각된 방향.

적용 예(대상 문장 형태): public-contract §1 `An export with no consumer carries a stated intent — or gets removed.` · structure §1 `A cycle is two units pretending to be one.` · reuse-first §1은 이미 볼드(4단계 채택분— R2b에서 그대로).

**기준선**: 현행 배포본 == `arms/R2r`이어야 한다(R2r = R3에서 reuse-first만 볼드 교체 = 4단계 반영 후 배포본) — V1이 14/14 diff로 검증. 계기 기준선은 기존 데이터 재사용: iC 현행 = R2r 6/8(75.0%)·R3 5/10(50.0%), iL 현행 = R3 1/8(12.5%), iK 현행 = stage3 R2 부분점수 5/9(완전 준수 0/3).

**사전 판정 기준 (실행 후 변경 금지)** — 지표는 완전 준수율(full-pass):

- **채택**: `iL에서 R2b ≥ 37.5%(R3+25%p)` **또는** `iC에서 R2b ≥ 75.0%(R3+25%p)` — 그리고 다른 계기에서 −25%p 초과 퇴행이 없고 iK 부분점수가 기존(5/9) 대비 악화 방향이 아니면 채택.
- **기각**: 위 미충족 — 전면 볼드는 기각하고 R2r 단독 유지. iC의 R2b 런은 표적 규칙 문면이 R2r과 동일하므로 R2r 재검증 데이터로 병기(주변 13종 볼드 차이는 iC 행동에 미미하다는 전제를 명시하고 별도 집계 + 참고 합산).
- 한계 명시: n=8·25%p 게이트는 결정 절차이지 통계적 유의성 주장이 아니다(4단계와 동일 문구).

**벤치 격리 규약**: stage3 §0과 동일(무개입, haiku, general-purpose, prepare 출력 그대로, grade.mjs, 웨이브 8~10, 실패 시 같은 rep 1회 재시도). 로그 `<SCRATCH>/results-stage5.jsonl`, 실행 디렉터리 `<SCRATCH>/bench-runs-stage5/`. grade.mjs는 [S4-계기수정]으로 `R2b` 파싱 가능.

**불변식**: 볼드 처리만이므로 문면 불변 — `> **Precedence**:`·`rests on`·B6 쌍·러너명 0·`8 lines` verbatim·관용구 2종·조건부 frontmatter 전부 유지되어야 하며, V3 반영 시 `yarn workspace @ogham/seiri test:run`(+ filid 파일 변경 시 filid도)이 기계 검사.
