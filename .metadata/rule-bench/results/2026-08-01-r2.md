**판정: 측정 가능한 매직워드 효과 없음** — 차이는 노이즈 범위이며 방향도 역전(제거 쪽이 근소 우위). 규칙 배치는 양 암 모두 14종 정상 확인. 부수 발견: haiku의 규칙-준수는 결정적이 아니라 **확률적**이다 — 1단계 iC의 R1·R2 만점(각 n=3)은 소표본 상방이었고, 결합 추정은 규칙-있음 9/16(56%) vs R0 0/2로 리프트 방향은 유지되나 크기는 하향 조정된다. 상위 모델에서는 iC 자체가 R0 포화라 매직워드 논점이 성립하지 않는다. 결론: **v2의 Ask-yourself 13/14 제거는 이 계기가 감지할 수 있는 어떤 손실도 만들지 않았고, 남긴 1개(reuse-first §1)의 하중 증거도 없다** — 마지막 1개의 제거 여부는 사용자 결정으로 남긴다(현행 유지가 기본값).

### 2단계 후속 항목

- opus iE~iJ 48런 + sonnet iJ 3런(새 세션에서 `prepare.mjs`/`grade.mjs` 재사용, run 디렉터리는 재생성 필요).
- haiku iC 변동성 정량화(n≥10)와 saturated 이슈의 고감도 변형은 기존 후속 제안과 통합.

## 한계

- 계기는 haiku 단일샷 fenced-subagent 프록시 — 장기세션·컴팩션 체제, 훅 주입 채널, 상위 모델 거동은 측정 밖(d9와 동일). 주변 세션 컨텍스트 오염은 3암 공통 상수로 통제.
- 포화 이슈 7종은 상한 효과로 R1↔R2 차이에 둔감 — 무회귀 주장에는 충분하나, 개별 조항의 절대 가치 측정으로는 부적합. 더 어려운 픽스처 변형(형제 모범 제거, 다단계화)이 후속 감도 개선안.
- N=3/셀 — 분산 추정은 거칠다. 판별 이슈(iC)의 0↔100% 격차는 N에 둔감.

## 후속 제안 (미실행)

- 포화 이슈의 고감도 변형(모범 형제 제거판) 추가로 S1·S2 조항 단위 재측정.
- 컴팩션·다단계 체제의 메인세션 실측(d9부터의 미해결 항목).
- 플러그인 버전 범프·커밋·릴리즈는 사용자 결정(Changesets 은퇴 상태라 릴리즈 플로우 별도 확인).
- 주의: 설치된 seiri/filid 플러그인 캐시는 아직 v1 템플릿을 담고 있어, 커밋·플러그인 갱신 전까지 이 저장소의 새 `.claude/rules` 사본이 상태 훅에서 "드리프트"로 보일 수 있다 — 재설치(버전 반영) 시 해소되는 과도기 상태.
