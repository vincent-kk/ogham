# 2026-08-30 규칙 정리 벤치 — R4/R5/R5p

## 결론

**D6: R5 채택.** R4의 의미 보존 압축은 공통 9이슈에서 R3c보다 낮아진 셀이 없었고, `cognitive-discipline`을 제외한 R5는 직접 표적 iE에서 luna 5/5, sol 3/3 full-pass였다. R5p는 측정된 naming·code-comments 프로브에서 비회귀였지만 context-efficiency·structure 직접 계기가 없고 iJ가 양쪽 0/5라 추가 은퇴 근거로는 부족했다.

원자료는 [2026-08-30-r4.jsonl](./2026-08-30-r4.jsonl)에 있다. `model|issue|arm|rep` 키로 158행을 검사한 결과 누락 0, 초과 0, 중복 0이다. shown 테스트는 158/158 런에서 통과했다.

## 실행 조건과 사전 기준

기존 계획의 Claude haiku/sonnet/opus 실행기를 이 호스트에서 사용할 수 없어, 같은 비용·역량 층의 `gpt-5.6-luna`/`gpt-5.6-terra`/`gpt-5.6-sol`로 대체했다. 암 비교는 같은 모델 안에서만 했고 과거 Claude 결과와 합치지 않았다.

- Stage A 비회귀: 같은 모델·이슈에서 `full-pass(후보) ≥ full-pass(R3c) - 1`.
- 규칙 은퇴 근거: 비회귀에 더해 직접 표적 계기와 높은 절대 full-pass가 필요하다. 0=0 동률은 근거가 아니다.
- Stage B “모델 기본기”: 각 모델·이슈에서 `R0 ≥ 4/5`이고 `R0 ≥ R4`여야 한다.
- full-pass는 shown과 hidden이 모두 전부 통과한 런이다. 표의 hidden은 전체 assert 합이다.

- 이 벤치는 규칙 파일 채널만 재며 스킬·훅을 배치하지 않는다. 단일샷이므로 장기 세션, 컴팩션, 스킬 미발화의 누적 위험은 측정 밖이다.
