## Purpose

yt-dlp 바이너리 획득·실행·정보 추출 서브시스템.

## Conventions

- 쿨다운 또는 명시적으로 고정한 버전만 획득하고, 체크섬 검증을 마친 스테이징 파일을 원자적으로 설치한다. 미검증·부분 바이너리가 실행되는 것을 막는다.
- 동일 extractor의 인자는 하나로 병합한다. yt-dlp가 중복 플래그의 마지막 값만 사용하므로 병합하지 않으면 player_client 설정이 유실된다.
- 호출자는 불변 실행 플래그를 우회하지 않는다. HTTP·설치 I/O는 바이너리 획득 영역에 격리하고 실행 실패는 타입 있는 오류로 정규화한다.

## Boundaries

### Always do

- 쿨다운으로 고정한 버전을 체크섬 검증 후 설치한다
- 실행 실패를 타입이 있는 에러로 정규화한다

### Ask first

- 바이너리 획득 정책·불변 실행 플래그 변경

### Never do

- 검증 없이 바이너리를 설치하거나 임의 버전을 받는다
- `--ignore-config`/`--no-warnings` 실행 불변식을 깬다
