## Purpose

기능별 수직 슬라이스 모음. 각 기능은 도구·operation·후처리를 한 fractal 노드에 응집한다.

## Conventions

- 각 기능은 도구·추출·후처리를 함께 소유한다. 기능 사이의 공통 요구는 공유 계층에서 해결하여 슬라이스끼리 내부 구현에 결합하지 않게 한다.
- 새 기능의 공개 도구는 기능 배럴에서 재노출한다. 등록 계층이 슬라이스 내부 배치를 알 필요가 없게 한다.

## Boundaries

### Always do

- 기능 간 의존은 공유 계층을 경유한다

### Ask first

- 새 기능 슬라이스 추가

### Never do

- 기능 슬라이스끼리 서로의 내부 파일을 직접 import한다
