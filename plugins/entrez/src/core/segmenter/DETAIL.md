# segmenter — Contract

## Requirements

- ESearch의 10,000 UID 상한을 우회하기 위해 날짜 버킷을 재귀 분할한다. 전수 수집은 각 버킷이 상한 이하로 나뉠 때 가능하며, 더 나눌 수 없는 상한 초과를 숨기지 않아야 한다.
- 버킷은 비중첩 완전 분할이다 — 누락도 중복도 만들지 않는다.
- 분할 후 재조회한 빈 버킷은 수집 대상에서 제외한다. 입력 전체가 상한 이하라면 재조회 없이 원 범위를 유지하므로 0건 범위도 남을 수 있다. 최대 깊이에 도달하거나 날짜를 더 나눌 수 없는데 상한을 넘으면 capped로 표시해 전수 수집으로 오인하지 않게 한다.
- 네트워크는 `CountFn` 으로 주입한다 — 이 모듈은 NCBI 를 직접 호출하지 않는다.

## API Contracts

호출 형태와 구체적인 반환 값은 공개 진입점과 테스트에서 확인한다.

## Acceptance Criteria

### AC-segment-partition — 완전 분할

- 날짜 분할은 원 범위를 빈틈없이 덮고 서로 겹치지 않으며, 그중 재조회 결과가 빈 범위만 반환 대상에서 제외할 수 있다.
- 상한 이하 입력의 원 범위는 재조회 없이 반환할 수 있어 빈 하위 버킷 제외 규칙과 구분한다.

### AC-segment-cap-marking — 상한 표시

- 최대 깊이에 도달하거나 날짜를 더 나눌 수 없는 상한 초과 버킷은 capped로 표시한다.

### AC-segment-purity — 주입 경계

- 모듈이 네트워크를 직접 호출하지 않고 주입된 `countFn` 만 쓴다.
