# manifestSave

## Purpose

매니페스트 저장 도구 핸들러.

## Conventions

전체 교체이므로 호출자가 완결된 문서를 넘긴다. 전송 클라이언트의 문자열 인코딩을 검증 전에 해독한다.

## Boundaries

### Always do

- 요약 계산과 실행 경로 정책은 core에 위임한다. 핸들러는 전송 입력 해독·공유 도메인 스키마 검증·원자적 저장을 조립하여 검증되지 않은 입력이 디스크에 닿지 않게 한다.

### Ask first

- inputSchema 변경

### Never do

- 도메인 스키마·요약 계산·실행 경로 규칙을 핸들러에서 재구현 — 저장과 조회의 계약이 갈라지는 것을 막는다.
