# runIdGenerator

## Purpose

날짜와 최소 세 자리 순번으로 실행 ID를 생성하고 실행 디렉터리를 배타적으로 예약한다. 조회 도구가 사용하는 ID 형식 판별과 날짜·숫자 순번 정렬도 소유한다.

## Conventions

저장 카운터 대신 실제 실행 디렉터리를 기준으로 삼아 카운터와 디렉터리의 불일치를 피한다.

## Boundaries

### Always do

- 실행 디렉터리의 배타적 생성으로 기존 ID와 충돌하지 않는 순차 번호 예약
- 예약 경합은 다음 순번으로 재시도하고 그 밖의 파일시스템 실패는 호출자에게 전파
- 조회의 ID 필터·정렬은 공통 표면을 제공하여 최신 조회와 목록 순서가 갈라지지 않게 한다

### Ask first

- ID 형식 변경

### Never do

- 순환 의존성 도입
