# jobStore — Contract

## Requirements

- 잡은 프로세스 수명의 메모리 상태로만 관리한다. 디스크 워크스페이스와 달리 재시작 후 복구를 약속하지 않는다.
- 취소 신호는 등록 컨트롤러를 통해 전파하여 상태만 취소되고 자식이 살아 있는 일을 막는다.
- 보관 상한 초과 시 오래된 종료 잡부터 제거한다. 실행 중 잡을 버리면 취소·조회 경로를 잃는다.

## API Contracts

- 조회·취소·갱신은 같은 프로세스 레지스트리를 공유한다. 산출물의 디스크 수명과 잡 식별자의 수명은 같지 않다.
- 미등록 갱신은 no-op이며 취소는 종료·미등록을 구분한다. 실행 중인 잡은 보관 상한 때문에 제거하지 않는다.

## Acceptance Criteria

구체적인 동작과 수치 기준은 소유 모듈의 테스트가 고정하며, 이 문서는 그 선택의 이유와 변경 경계를 기록한다.

## Last Updated

잡 수명·취소·보관 상한 계약의 내용이나 적용 범위가 바뀔 때 갱신한다.
