# commandGate — Contract

## Requirements

- 실행 전 금지 호출을 정적으로 검사하여 알려진 프로세스·네트워크·파일시스템 탈출 호출의 실행을 막는다.
- 점 표기 호출도 같은 대상으로 검사하고 서로 다른 위반을 모두 보고한다. 첫 위반만 고친 뒤 반복 실행하는 일을 줄인다.
- 설치 명령은 허용 목록에서만 해석하며 통계 타당성은 판단하지 않는다.

## API Contracts

- 정적 금지 호출 검사는 best-effort이며 완전한 OS 격리를 뜻하지 않는다. 임의 파일 쓰기·dual-use URL 리더의 잔여 위험은 수용하며 cwd·env 격리로 범위를 줄인다.
- 설치 경로는 승인된 바이너리와 고정 인자로만 해석한다. 임의 인자를 허용하면 허용 목록이 셸 실행 우회로가 된다.

## Acceptance Criteria

구체적인 동작과 수치 기준은 소유 모듈의 테스트가 고정하며, 이 문서는 그 선택의 이유와 변경 경계를 기록한다.

## Last Updated

정적 금지 호출·설치 허용 목록·잔여 위험 정책의 내용이나 적용 범위가 바뀔 때 갱신한다.
