# workspace — Contract

## Requirements

- 실행 공간과 입력·산출 영역을 분리하고 workspace 식별자의 경로 탈출을 거부한다.
- 수집 허용 목록과 해시를 유지하여 허용된 산출물의 무결성을 추적한다. 디렉터리는 `DIR_MODE`(0700)로 생성하여 실행 공간의 접근 범위를 제한한다.
- stateless 재사용은 잔여 산출물을 지우고 파일 재사용 모드는 데이터와 최초 생성 시각을 보존한다. 두 모드의 재현성 약속을 섞지 않는다.

## API Contracts

- 아티팩트는 허용 영역의 realpath 안에서만 수집한다. 심링크 탈출은 정책 실패이며 누락으로 감추지 않는다.
- kind는 매니페스트를 우선하고 없으면 확장자로 추론한다. 매니페스트 부재는 정상적인 무산출 상태일 수 있다.
- 재사용 워크스페이스의 수명은 최초 생성 기준이다. 파일 갱신이 TTL을 무한 연장하지 않게 한다.

## Acceptance Criteria

구체적인 동작과 수치 기준은 소유 모듈의 테스트가 고정하며, 이 문서는 그 선택의 이유와 변경 경계를 기록한다.

## Last Updated

격리·아티팩트 수집·워크스페이스 재사용 계약의 내용이나 적용 범위가 바뀔 때 갱신한다.
