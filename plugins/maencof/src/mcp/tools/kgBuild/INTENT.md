# kgBuild

## Purpose

지식 그래프 빌드 도구. 전체/증분 빌드 지원.

## Conventions

서고는 그래프 스냅샷 밖이므로 무변경 빌드에도 열거 인덱스를 다시 스캔한다. 빌드가 문서 읽기를 조립하고 파싱·그래프 계산은 core에 위임해 알고리즘을 디스크와 결합하지 않는다.

## Boundaries

### Always do

- 개별 파싱 실패는 격리하고 응답 실패 목록에 상한 적용

### Ask first

- 입출력 스키마 변경

### Never do

- core의 파싱·그래프 계산을 도구에 복제
