# maencofMove — DETAIL

## Requirements

- 대상 쓰기 성공 뒤에만 소스를 삭제한다. 전체 배치 원자성이나 backlink 수리는 제공하지 않으며 호출자가 참조 보존과 부분 실패를 복구한다.
- L1 소스는 보호하고 양쪽 경로의 vault 봉쇄와 쓰기 직전 frontmatter 검증을 유지한다.
- L5 승격 시 buffer 전용 필드를 제거하고 target_sub_layer 미지정 시 sub_layer를 제거해 레이어 전이의 잔재를 남기지 않는다.
- 대상 디렉터리는 이미 존재하는 실명과 맞아야 하므로 슬러그화하지 않는다. 허용 문자·깊이·traversal·숨김 세그먼트와 레이어/서고 예약 루트를 검증해 관리 경로를 오염시키지 않는다.
- 평면 레이어에는 중첩 디렉터리를 허용하지 않되 명시적 빈 문자열은 root 선택이다. 같은 레이어 재배치는 sub_layer 또는 subdirectory가 지정되어야 한다.
- 소스의 읽기 가능 범위와 색인 자격은 다르므로 allowNonLayerPath를 사용한다. 레이어 밖 소스도 이동할 수 있어야 한다.

## API Contracts

이동은 basename을 유지하지만 소스의 중첩 디렉터리를 자동 보존하지 않는다. 대상 위치는 명시된 레이어·서브레이어·서브디렉터리로 결정한다. reason·confidence는 호출자 문맥용이며 기록하거나 응답에 에코하지 않는다.

디렉터리 세그먼트는 이미 존재하는 실명과 맞아야 하므로 슬러그화하지 않는다. 명시적 빈 target_subdirectory는 root 선택이고 생략과 다르다. 전체 배치 원자성과 backlink 수리는 호출자가 책임진다.
