# backupPath

## Purpose

파일 덮어쓰기 전 현재 시각으로 타임스탬프 백업 경로를 만드는 명명 유틸리티. 덮어쓰기 전 백업 명명 규칙의 단일 진실 원천.

## Conventions

파일 복사는 호출자가 소유하여 경로 생성이 저장 책임을 갖지 않게 한다.

## Boundaries

### Always do

- 콜론·점을 하이픈으로 치환해 파일시스템 안전한 접미사 생성
- 현재 시각은 백업 접미사 명명에만 사용하고 파일 복사는 호출자가 수행 — 경로 생성이 저장 책임까지 갖지 않게 한다

### Ask first

- 백업 접미사 포맷 변경

### Never do

- 파일 I/O 수행
