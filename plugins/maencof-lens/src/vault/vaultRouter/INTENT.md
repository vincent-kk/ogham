## Purpose

다중 볼트 이름→설정 해석기. 볼트 이름으로 설정을 조회하고 기본 볼트를 반환한다.

## Conventions

- 이름 오타는 기본 볼트로 바꾸지 않고 오류로 알린다. 실패보다 엉뚱한 볼트를 읽는 일이 더 위험하다.
- 검증된 설정만 받으며 반환 객체는 공유 참조다. 호출자는 읽기 전용으로 다루고 설정 변경 시 라우터를 새로 만든다.

## Boundaries

### Always do

- 미등록 볼트 이름을 오류로 알리고 반환 설정을 읽기 전용 참조로 취급한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
