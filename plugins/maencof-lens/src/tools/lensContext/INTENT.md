## Purpose

`context` 툴 핸들러. 토큰 예산 기반으로 볼트 문서를 조합하여 컨텍스트 블록을 생성한다.

## Conventions

- 조합·토큰 예산은 maencof가 소유하며 이 어댑터는 레이어 상한을 적용한다. 본문 없는 문서 선택 결과도 허용하여 호출자가 필요한 문서만 따로 읽을 수 있게 한다.

## Boundaries

### Always do

- 문서 조합은 maencof에 위임하고 전달 레이어를 볼트 상한 안으로 제한한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
