## Purpose

`read` 툴 핸들러. 경로로 단일 볼트 문서를 읽고 레이어 필터를 적용한다.

## Conventions

- 그래프 없이 볼트 경로로 읽으며, 본문 반환 전에 레이어를 판정한다. 차단한 문서 본문이 오류 응답에 섞이면 필터의 의미가 없어진다.

## Boundaries

### Always do

- 상한 밖 문서의 본문을 반환하지 않고 차단 레이어를 소비자에게 알린다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
