# lensRead — Contract

## Requirements

- maencof의 읽기 핸들러가 그래프가 아니라 볼트 경로를 받으므로 인덱스가 없어도 문서를 읽는다.
- 볼트 상한 판정은 본문 반환 전에 끝낸다. 차단된 본문이 오류 응답에 섞이면 필터가 무의미하다.
- 레이어 정보가 없다는 이유만으로 읽기를 차단하지 않는다. 차단 메시지는 레이어를 밝혀 소비자가 설정 변경 필요성을 판단하게 한다.
- 볼트 쓰기나 인덱스 생성은 이 경로의 책임이 아니다.

## API Contracts

- 차단 결과는 본문 없이 레이어 사유만 반환하고 서버가 MCP 오류로 승격한다. 레이어 미상과 허용된 문서는 원본 응답을 유지한다.

## Acceptance Criteria

### AC-restricted-layer — 상한 밖 차단

- 유효 레이어 밖 문서를 요청하면 `error` 필드만 담긴 객체가 나온다.
- 그 응답에 문서 본문이 없다.
- 메시지에 차단된 레이어 번호가 포함된다.

### AC-missing-layer-passthrough — 레이어 미상 통과

- 결과 `node` 에 `layer` 가 없으면 차단하지 않고 원본 결과를 돌려준다.
- `node` 자체가 없어도 throw 하지 않는다.

### AC-read-only — 읽기 전용

- 이 경로에서 볼트에 쓰기가 없다.
- 그래프 인덱스를 만들거나 갱신하지 않는다.

## Last Updated
