## Purpose

`status` 툴 핸들러. 볼트 인덱스 상태(노드 수, 만료 여부, 건강 상태)를 확인한다.

## Conventions

- 인덱스 집계를 재계산하지 않고 만료 경고와 읽기 전용 안내만 보탠다. legacy 마이그레이션과 일반 갱신은 조치가 다르므로 구분한다.
- 문서 본문이 없는 집계 응답에는 레이어 필터를 적용하지 않는다.

## Boundaries

### Always do

- 만료 유형별 복구 안내와 읽기 전용 표시를 유지하여 렌즈에서 재구축을 시도하지 않게 한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
