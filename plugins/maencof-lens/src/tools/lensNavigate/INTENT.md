## Purpose

`navigate` 툴 핸들러. 특정 노드의 그래프 이웃(인바운드/아웃바운드 링크, 부모/자식)을 탐색한다.

## Conventions

- maencof 이웃 탐색은 레이어를 모르므로 응답에서 상한을 적용한다. 레이어 미상 항목은 남겨 그래프가 끊긴 것처럼 보이지 않게 한다.

## Boundaries

### Always do

- 이웃 응답에 상한을 적용하되 원본 객체와 레이어 미상 항목을 보존한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
