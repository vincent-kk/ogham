# lensNavigate — Contract

## Requirements

- 그래프 이웃 탐색은 maencof가 소유한다. 이 어댑터는 탐색을 재구현하지 않는다.
- 본가 탐색이 레이어를 모르므로 이웃 응답을 볼트 상한으로 후처리한다. 호출별 상한 재정의는 받지 않는다.
- 대상 노드가 상한 밖이면 `read` 도구와 같은 제한 레이어 오류만 반환한다. 대상 문서의 경로·제목이나 이웃을 함께 반환하면 상한 밖 문서가 드러난다.
- 레이어가 없는 항목은 유지한다. 정보 부재로 이웃을 지우면 그래프가 끊긴 것처럼 보인다.
- 원본 응답을 제자리에서 고치지 않는다. 캐시된 그래프 파생 객체의 오염을 막는다.
- 응답의 모든 노드는 복사하고 `outboundLinks`에서도 그래프상 상한 밖 레이어로 확인되는 경로를 제거한다. 링크의 `#조각`은 떼고 대상 문서를 찾되 남기는 링크 문자열은 바꾸지 않는다. 이웃 목록만 거르면 노드에 포함된 링크로 제한 문서 경로가 드러난다. 그래프에 없는 링크는 레이어 미상이므로 유지한다.
- 인덱스 부재는 결과 오류와 재색인 안내로 보고하며 렌즈에서 재구축하거나 볼트에 쓰지 않는다.

## API Contracts

- 허용된 대상의 응답에서는 문서 식별 정보를 담지 않는 집계 필드를 보존하고 배열이 아닌 값이나 레이어 미상 항목을 임의로 삭제하지 않는다. 상한 밖 `parent`는 부모가 없는 경우와 같이 `undefined`로 처리한다.
- 인덱스 부재와 maencof의 결과 오류는 렌즈 재색인 안내로 치환한다.

## Acceptance Criteria

### AC-post-filter-neighbors — 이웃 후처리

- 볼트 상한 밖 레이어 노드가 `inbound`·`outbound`·`children`·`siblings`·`crossLayer`·`domain` 결과에서 빠지고 `parent`에도 실리지 않는다.
- 대상 `node`가 상한 밖이면 문서 식별 정보 없는 제한 레이어 오류만 반환한다.
- 대상·부모·이웃 노드의 `outboundLinks`에서도 `#조각`을 떼고 찾은 문서가 상한 밖이면 해당 링크가 빠지며 허용된 링크와 레이어 미상 링크는 원래 문자열로 유지된다.
- `layer` 가 없는 항목은 그대로 남는다.
- 배열이 아닌 값이 들어와도 throw 없이 원본이 유지된다.

### AC-ceiling-only — 상한 고정

- 입력에 호출별 레이어 필터가 없고, 유효 레이어가 항상 볼트 상한과 같다.

### AC-index-absent — 인덱스 부재 보고

- `graph` 가 `null` 이면 throw 하지 않고 `error` 필드가 담긴 객체가 나온다.
- 그 문장이 재색인 수단을 지목한다.
