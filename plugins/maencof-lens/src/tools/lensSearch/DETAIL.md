# lensSearch — Contract

## Requirements

- 랭킹·시드 의미·선택 파라미터 기본값은 maencof가 소유한다. 시드 항목을 분해·정규화·번역하면 항목 간 합집합과 항목 안 AND 의미가 달라진다.
- 호출별 필터는 볼트 상한을 넓히지 못하며 빈 교집합도 그 상한으로 돌아간다.
- `SubLayer`를 직접 받아 넘긴다. 넓은 타입의 캐스팅은 본가 모델 축소를 가려 폐기값이 빈 결과로 보이게 한다.
- 본문·trace 옵션은 maencof에 위임한다. 샌드박스 에이전트가 별도 파일 Read 없이 본문을 받을 수 있게 하되 상한 밖 본문은 노출하지 않는다.
- cluster 열거는 본가에서 레이어를 거르지 않으므로 이 어댑터가 후필터한다. `clusterSize`는 전역 총원이며 필터 후 개수로 바꾸지 않는다.
- graph-null만 재색인 안내로 치환하고 입력 검증 오류는 그대로 전파한다. 모든 오류를 재색인 안내로 덮으면 호출자가 잘못된 입력을 고칠 수 없다.
- 인덱스 부재를 알아도 재구축하거나 볼트에 쓰지 않는다.

## API Contracts

- 선택 인자를 생략하면 어댑터 기본값을 주입하지 않는다. maencof의 기본값이 단일 출처다.

## Acceptance Criteria

### AC-layer-ceiling — 레이어 상한 적용

- `layer_filter` 가 볼트 상한 밖 레이어를 포함하면 상한 안 레이어만 maencof 핸들러에 전달된다.
- `layer_filter` 를 생략하면 볼트 상한 전체가 전달된다.
- 교집합이 비면 throw 없이 볼트 상한 전체로 되돌아간다.

### AC-seed-passthrough — 시드 무변형 전달

- 입력 `seed` 배열이 항목 수·순서·내용 그대로 maencof 핸들러에 도달한다.
- 선택 파라미터를 생략하면 기본값이 주입되지 않고 `undefined` 로 전달된다.

### AC-index-absent — 인덱스 부재 보고

- `graph` 가 `null` 이면 throw 하지 않고 `error` 필드가 담긴 객체가 나온다.
- 그 문장이 재색인 수단을 지목한다.
