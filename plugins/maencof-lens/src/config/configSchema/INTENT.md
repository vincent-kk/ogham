## Purpose

Zod 기반 설정 스키마 정의. `VaultConfig` 및 `LensConfig` 타입과 검증 스키마를 제공한다.

## Conventions

- 스키마 파싱과 수동 가드의 런타임 좁히기를 구분한다. 훅의 가드는 Zod를 싣지 않지만 필드는 스키마와 같은 변경에서 맞춰 계약이 갈라지지 않게 한다.

## Boundaries

### Always do

- 스키마와 수동 가드의 필드를 같은 변경에서 맞춰 설정 해석이 갈라지지 않게 한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
- Zod 스키마와 수동 가드 간 필드 불일치 허용 금지 — 스키마 수정 시 가드도 같은 PR에서 동기화
