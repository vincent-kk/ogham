## Purpose

2단계 레이어 필터링 로직. 볼트 설정 상한과 호출별 필터의 교집합을 계산하고 결과를 필터링한다.

## Conventions

- 빈 교집합은 볼트 상한으로 폴백한다. 결과에 레이어 정보가 없는 항목은 유지하여 정보 부재를 접근 금지 판정으로 바꾸지 않는다.

## Boundaries

### Always do

- 호출 필터가 볼트 상한을 넓히지 못하게 하고 빈 교집합도 그 상한으로 제한한다
- 이 경계의 계약 변경은 해당 검증과 함께 갱신하여 소비자와 구현이 어긋나지 않게 한다

### Ask first

- 공개 API 시그니처 변경
- 다른 모듈에 대한 새로운 의존성 추가

### Never do

- 순환 의존성 도입
- organ 경계를 넘는 직접 import
