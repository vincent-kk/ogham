# infra — 계층별 설정

## Purpose

사용자 기본값·프로젝트 기준선·런타임 밸브의 설정 읽기·쓰기를 소유한다. 개인 선호, 팀 정책, 일시적인 개입 조정의 소유권을 분리한다.

## Conventions

- 설정 키를 늘리기 전에 **"이 값의 진실을 누가 소유하는가"** 를 먼저 답한다. 저장소가 소유해야 할 값(검증 명령·임계치)은 여기 두지 않는다. 사본은 드리프트하고, 드리프트한 사본은 없느니만 못하다.
- 파일시스템이 이미 답하는 것(어떤 규칙이 배포됐는지)도 두지 않는다.

## Boundaries

### Always do

- 읽기 실패를 정상 상태로 다룬다 — 설정이 없는 프로젝트가 기본값이다.

### Ask first

- 새 설정 모듈 추가.

### Never do

- 오라클 값 보유.
- 세션 훅에서 쓰기.
