# directives

## Purpose

한 워크플로 동안 압축을 넘어 유지할 로컬 지침 묶음과 체크아웃별 연결 기록을 관리합니다.

## Conventions

MCP는 진입점을 사용하고 훅은 번들에 필요한 파일에 직접 접근합니다.

## Boundaries

### Always do

- 연결 변경을 잠금 안에서 적용하고 본문 읽기를 묶음 내부로 제한합니다.

### Ask first

- 주입 범위를 서브에이전트나 다른 체크아웃까지 넓힙니다.

### Never do

- 호스트 설정을 쓰거나 지침 경로의 심볼릭 링크를 따라갑니다.
