# gates — 작업 상태 원장

## Purpose

seiri 가 소유하는 네 번째 상태인 작업 상태를 원장 하나로 해석하고 갱신한다. 훅과 MCP 는 같은 파서를 공유하며, 원장은 세션과 무관하게 작업 이름으로 이어진다.

## Conventions

- 체크박스는 주장이고 `EVIDENCE` 가 증명이다. 체크됐어도 증거가 `pending` 이면 미충족이다.
- 읽기는 관대하고 실패 시 상태 없음으로 돌아간다. 쓰기는 작업별 락과 원자적 교체를 거친다.
- 실행 가능한 게이트의 증거는 관측된 도구 결과에서만 만들고, 수동 증거와 포기는 명시적 API 로만 기록한다.
- 결과 조건의 검사는 `CHECK` 가 소유하고, `EXPECT` 는 그 조건이 충족됐을 때만 출력되는 리터럴 문자열을 확인한다.
- 훅 도달 코드는 번들 크기 가드 때문에 필요한 organ 을 직접 import 한다.

## Boundaries

### Always do

- 같은 명령과 일치하는 모든 작업 원장을 갱신하고 작업별 상태를 따로 계산한다.
- 회귀·포기·위임자 증거를 원장 안에 보이는 표지로 남긴다.

### Ask first

- 원장 문법, 증거 상한, 작업 이름 문법 변경.
- 공개 배럴의 추가·제거 또는 시그니처 변경.

### Never do

- `CHECK` 를 실행하거나 프로세스를 띄우기.
- `session_id` 를 읽거나 저장하기.
- 원장 밖에 포인터·캐시·등록 상태를 만들기.
